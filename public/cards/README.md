# Карточка суреттері (сайт кодында сақталатын қабат)

Бұл бумаға қосылған сурет БАРЛЫҚ қолданушыға тұрақты көрінеді —
құрылғыдағы генерациядан басым.

Атау форматы: `{lang}-{slug}.jpg`
- lang: en немесе zh
- slug: сөз кіші әріппен, бос орын → дефис (мыс. `en-dog.jpg`, `en-wake-up.jpg`)
- қытай иероглифтері: Unicode кодтары (мыс. 你好 → `zh-u4f60u597d.jpg`)

Ұсынылатын өлшем: 384×384 JPEG (~30-60КБ).
Стиль: жұмсақ 3D-мультяш, пастель фон, мәтінсіз.
